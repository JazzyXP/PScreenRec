# Install through Creative Cloud Desktop

[English](#windows) · [Русский](#windows-ru)

## Windows

1. Install Adobe Creative Cloud Desktop and Photoshop, and sign in to Creative Cloud.
2. Save your drawings and close Photoshop.
3. [Download the Windows CC installer](https://github.com/JazzyXP/PScreenRec/releases/download/v0.5.9/PScreenRec-0.5.9-Setup-CC.exe), run it and follow the prompts.
4. Open Photoshop → **Plugins → PScreenRec → PScreenRec** and enable **Record this document**.

The installer includes the independent plugin and its helper. Adobe's installation service installs the panel; a Marketplace listing is not required. Python is included; the initial FFmpeg download requires internet access. Recordings and settings are preserved when updating over an existing installation. Choose either the CC installer or the direct installer, not both.

## Mac

Use the [Mac CC installer](https://github.com/JazzyXP/PScreenRec/releases/download/mac-v0.5.13/ProcessRecorder-0.5.10-Mac-arm64-Adobe-CC.dmg) and follow the [Mac installation guide](MAC_INSTALL.md). Creative Cloud Desktop must be installed. The installer includes both the independent plugin and helper; it is separate from the Marketplace submission.

## Windows (RU)

1. Установите Adobe Creative Cloud Desktop и Photoshop, войдите в Creative Cloud.
2. Сохраните рисунки и закройте Photoshop.
3. [Скачайте Windows-установщик через CC](https://github.com/JazzyXP/PScreenRec/releases/download/v0.5.9/PScreenRec-0.5.9-Setup-CC.exe), запустите его и следуйте подсказкам.
4. Откройте Photoshop → **Plugins → PScreenRec → PScreenRec** и включите **«Записывать этот документ»**.

Установщик содержит независимый плагин и помощник. Панель устанавливается механизмом Adobe, публикации в Marketplace ждать не нужно. Python включён, для первоначальной загрузки FFmpeg нужен интернет. При обновлении поверх установленной версии записи и настройки сохраняются. Выберите один установщик: через CC или напрямую, ставить оба не нужно.

## Mac (RU)

Используйте [Mac-установщик через CC](https://github.com/JazzyXP/PScreenRec/releases/download/mac-v0.5.13/ProcessRecorder-0.5.10-Mac-arm64-Adobe-CC.dmg) и [инструкцию для Mac](MAC_INSTALL.ru.md). Требуется установленный Creative Cloud Desktop. Внутри независимый плагин и помощник; это отдельный вариант от заявки в Marketplace.
