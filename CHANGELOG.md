# Release notes

[English](#windows-059) · [Русский](#windows-059-ru)

## Mac 0.5.10

- Standalone Mac installers include the plugin, local helper, Python and FFmpeg.
- Choose direct installation or installation through Creative Cloud Desktop.
- Canvas recording, continuation across PSD/PSB sessions, trim/crop preview and MP4 export through the system save dialog.
- English/Russian interface follows Photoshop. Apple Silicon, macOS 15+; Photoshop 27.10+ is recommended.

The helper is unsigned and not notarized; follow the app-specific opening instructions. Recording with Creative Cloud completely absent has not been verified. The Windows folder and diagnostic shortcuts are not included in this Mac version.

## Mac 0.5.10 (RU)

- Установщики включают плагин, локальный помощник, Python и FFmpeg.
- Доступна прямая установка или установка через Creative Cloud Desktop.
- Запись холста, продолжение записи PSD/PSB, выбор кадров, кроп и экспорт MP4 через системное окно сохранения.
- Русский или английский интерфейс по языку Photoshop. Apple Silicon, macOS 15+; рекомендуется Photoshop 27.10+.

Помощник без подписи и нотариализации Apple; порядок открытия описан в инструкции. Запись при полностью отсутствующем Creative Cloud отдельно не проверена. Кнопок папки кадров и диагностики из Windows в этой Mac-версии пока нет.

## Windows 0.5.9

- Added a folder icon beside the frame count. Click it to prepare JPEG copies of the current document's frames and open their folder. The source frames remain in the local database.
- The requested folder opens in front of Photoshop.
- Added a bug icon beside the plugin version. It creates a local diagnostic log you can share when reporting a problem. Nothing is uploaded automatically.
- Diagnostic reports exclude artwork, document names, file paths and connection tokens.

Save your drawings and close Photoshop, then run the new installer over the previous version. Recordings and settings are preserved; uninstalling first is not necessary.

This update is for Windows. The Mac downloads have separate versions and do not yet include these new folder and diagnostic controls.

## Windows 0.5.9 (RU)

- Рядом с количеством кадров появилась иконка папки. Она подготавливает JPEG-копии кадров текущего рисунка и открывает их папку. Исходные кадры остаются в локальной базе.
- Папка кадров открывается поверх Photoshop.
- Рядом с версией плагина появился жучок. По нажатию создаётся локальный файл диагностики, который можно прислать вместе с описанием проблемы. Автоматически ничего не отправляется.
- В диагностический отчёт не включаются рисунки, имена документов, пути файлов и ключи подключения.

Для обновления сохраните рисунки, закройте Photoshop и запустите новый установщик поверх предыдущей версии. Записи и настройки сохраняются; предварительно удалять программу не нужно.

Это обновление Windows. У Mac отдельные версии: новые кнопки папки и диагностики в них пока не добавлены.
