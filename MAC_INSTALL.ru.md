# Установка PScreenRec на Mac

[English](MAC_INSTALL.md) · [Русский](MAC_INSTALL.ru.md)

Apple Silicon (M1 и новее), macOS 15+. Рекомендуется Photoshop 27.10+. Эти загрузки не поддерживают Intel. Выберите один способ установки. Оба установщика версии 0.5.10 содержат одинаковый независимый плагин, локальный помощник, Python и FFmpeg.

## Прямая установка

1. Сохраните рисунки и закройте Photoshop.
2. [Скачайте прямой установщик](https://github.com/JazzyXP/PScreenRec/releases/download/mac-v0.5.13/ProcessRecorder-0.5.10-Mac-arm64-Standalone-Experimental.dmg) и откройте DMG.
3. Запустите приложение Install внутри и следуйте подсказкам. При первой установке выберите родительскую папку для ProcessRecorderData.
4. Выполните шаги из раздела «Безопасность и первый запуск» ниже.

Установщик не вызывает Creative Cloud или службу установки Adobe. Запись при полностью отсутствующем Creative Cloud отдельно не проверена.

## Установка через Adobe CC

1. Установите Creative Cloud Desktop и Photoshop, войдите в Creative Cloud.
2. Сохраните рисунки и закройте Photoshop.
3. [Скачайте CC-установщик](https://github.com/JazzyXP/PScreenRec/releases/download/mac-v0.5.13/ProcessRecorder-0.5.10-Mac-arm64-Adobe-CC.dmg), откройте DMG и запустите Install внутри. Следуйте подсказкам.
4. Выполните шаги из раздела «Безопасность и первый запуск» ниже.

Используется механизм установки Adobe; ждать публикации в Marketplace не нужно. Ставить оба варианта не нужно.

## Безопасность и первый запуск

1. Установщик без подписи и нотариализации Apple. Если macOS блокирует его из-за непроверенного разработчика, откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** для этого приложения. Подтвердите пароль или Touch ID. При сообщении о вредоносном ПО или повреждённом файле остановитесь и пришлите точный текст. Не отключайте защиту системы.
2. Если потребуется **«Мониторинг ввода»**, разрешите его комплектному Python.app по пути, который показывает установщик.
3. Откройте Photoshop → **Plugins → PScreenRec → PScreenRec** и включите **«Записывать этот документ»**.
4. Если нужен файл подключения, выберите `~/Library/Application Support/ProcessRecorder/connection.json`. Никому его не передавайте.
5. После начала записи сохраните рисунок в PSD/PSB, чтобы позже продолжить тот же таймлапс.

## Обновление и записи

Закройте Photoshop и запустите выбранный установщик поверх предыдущей установки. Сохраняйте выбранную папку ProcessRecorderData: в ней хранятся записи, исходные кадры — в recordings.sqlite3, видео — в exports. Не включайте одновременно независимую и магазинную панели.

Для больших холстов рекомендуем **High**. Кратковременная смена курсора при захвате остаётся известным ограничением. Кнопок папки кадров и диагностики из Windows в этой Mac-сборке пока нет. Язык панели — русский или английский, по языку Photoshop.
