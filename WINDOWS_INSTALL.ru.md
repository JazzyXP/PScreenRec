# Установка PScreenRec на Windows

[English](WINDOWS_INSTALL.md) · [Русский](WINDOWS_INSTALL.ru.md)

Windows 10 / 11, x64, Photoshop 2024 (25.0) или новее. Выберите один способ ниже. В обоих вариантах одинаковый независимый плагин и локальный помощник; Python включён.

## Прямая установка

1. Сохраните рисунки и закройте Photoshop.
2. [Скачайте прямой установщик](https://github.com/JazzyXP/PScreenRec/releases/download/v0.5.9/PScreenRec-0.5.9-Setup.exe), запустите его и следуйте подсказкам.
3. Откройте Photoshop → **Plugins → PScreenRec → PScreenRec**.
4. Включите **«Записывать этот документ»**. Для следующих новых файлов есть **«Записывать новые документы»**.

Creative Cloud Desktop и UXP Developer Tool не нужны. Для первоначальной загрузки FFmpeg нужен интернет.

## Установка через Adobe CC

1. Установите Creative Cloud Desktop и Photoshop, войдите в Creative Cloud.
2. Сохраните рисунки и закройте Photoshop.
3. [Скачайте CC-установщик](https://github.com/JazzyXP/PScreenRec/releases/download/v0.5.9/PScreenRec-0.5.9-Setup-CC.exe), запустите его и следуйте подсказкам.
4. Откройте Photoshop → **Plugins → PScreenRec → PScreenRec** и включите **«Записывать этот документ»**.

Используется механизм установки Adobe; ждать публикации в Marketplace не нужно. Для первоначальной загрузки FFmpeg нужен интернет.

## Обновление и записи

Закройте Photoshop и запустите выбранный установщик поверх предыдущей версии. Записи и настройки сохраняются; предварительно удалять программу не нужно. Не включайте одновременно независимую и магазинную панели.

После начала записи сохраните рисунок в PSD/PSB, чтобы потом продолжить тот же таймлапс. Сохраняйте папку с данными записей. Если панель попросит файл подключения, выберите `%LOCALAPPDATA%\ProcessRecorder\connection.json`; никому его не передавайте.

Для больших холстов рекомендуем **High**, чтобы уменьшить нагрузку. Язык панели — русский или английский, по языку Photoshop.
